# Telegram-бот для мониторинга статусов задач

Telegram-бот для автоматического отслеживания изменений статусов задач через API с отправкой уведомлений в Telegram.

Бот периодически проверяет состояние задач, обнаруживает изменения и отправляет уведомления о новых статусах. Предусмотрена обработка ошибок API и Telegram, а также ведение журнала работы.

## Возможности

- периодический опрос API с интервалом 10 минут;
- проверка корректности и структуры ответов API;
- обнаружение изменений статусов задач;
- отправка уведомлений в Telegram при изменении статуса;
- обработка ошибок API и отправки сообщений;
- предотвращение повторной отправки одинаковых уведомлений;
- логирование событий и ошибок.

Поддерживаемые статусы:

- `approved` — задача успешно завершена;
- `reviewing` — задача находится на проверке;
- `rejected` — задача возвращена с замечаниями.

## Технологии

- Python 3.12
- Telegram Bot API 4.22
- Requests 2.32
- python-dotenv
- Logging

## Требования

- Python 3;
- токен API сервиса;
- токен Telegram-бота;
- идентификатор Telegram-чата для отправки уведомлений.

## Установка и настройка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Torb7/homework-bot
   cd homework-bot
   ```

2. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и получите токен.

4. Получите идентификатор Telegram-чата, в который будут отправляться уведомления.

5. Создайте в корне проекта файл `.env`:

   ```dotenv
   PRACTICUM_TOKEN=your_api_token
   TELEGRAM_TOKEN=your_telegram_bot_token
   TELEGRAM_CHAT_ID=your_chat_id
   ```

Все три переменные обязательны. Если хотя бы одна из них отсутствует или пуста, приложение записывает критическую ошибку в журнал и завершает работу.

## Запуск

Для запуска приложения выполните:

```bash
python homework.py
```

Для окружений, поддерживающих `Procfile`, используется следующая команда:

```text
worker: python homework.py
```

## Принцип работы

После запуска приложение:

1. Загружает переменные окружения из `.env`.
2. Проверяет наличие обязательных настроек.
3. Инициализирует временную метку последней проверки.
4. Отправляет запрос к API:

   `https://practicum.yandex.ru/api/user_api/homework_statuses/`

5. Проверяет структуру полученного ответа.
6. Определяет наличие новых или изменившихся статусов.
7. При обнаружении изменений формирует и отправляет уведомление в Telegram.
8. Обновляет временную метку последней проверки.
9. Повторяет цикл через 600 секунд.

Если изменений нет, приложение фиксирует это в журнале и продолжает работу.

Для предотвращения дублирования уведомлений одинаковые сообщения не отправляются повторно. Ошибки при этом продолжают фиксироваться в журнале.

## Обработка ошибок

Приложение обрабатывает следующие ситуации:

- отсутствие обязательных переменных окружения;
- недоступность API;
- некорректный или неожиданный ответ API;
- отсутствие обязательных ключей в ответе;
- получение неизвестного статуса;
- ошибки при отправке сообщений в Telegram.

Ошибки, связанные с обработкой ответа API, дополнительно отправляются в Telegram. Если Telegram API недоступен, информация об ошибке сохраняется в журнале.

## Логирование

Логирование осуществляется в стандартный поток вывода (`stdout`).

Каждая запись содержит дату и время события, уровень важности, имя функции и описание события.

Пример:

```text
2026-11-07 12:00:00,000 DEBUG get_api_answer Успешное завершение запроса...
```

В журнал записываются, в частности, следующие события:

- отсутствие обязательной переменной окружения — `CRITICAL`;
- успешная отправка сообщения в Telegram — `DEBUG`;
- ошибка отправки сообщения в Telegram — `ERROR`;
- недоступность endpoint или неожиданный ответ API — `ERROR`;
- отсутствие ожидаемых ключей в ответе API — `ERROR`;
- неизвестный статус домашней работы — `ERROR`;
- отсутствие новых статусов — `DEBUG`.

Ошибки, возникшие при обработке ответа API, также отправляются в Telegram.
Если Telegram API недоступен, сообщение отправить невозможно, поэтому ошибка
только записывается в журнал.
